
# MYBLOG - HỆ THỐNG QUẢN LÝ BLOG

## 1. Giới thiệu dự án

MyBlog là dự án thực hành xây dựng website blog sử dụng ASP.NET Core Razor Pages.

Dự án hướng đến việc xây dựng một trang web cho phép người dùng đăng ký tài khoản, đăng nhập, tạo bài viết và bình luận trên các bài viết.

## 2. Công nghệ sử dụng

- ASP.NET Core
- C#
- HTML
- CSS
- JavaScript
- Visual Studio 2022

## 3. Các chức năng trong Sprint 1

Dự án dự kiến triển khai 4 chức năng chính:

- Đăng ký tài khoản (User Registration).
- Đăng nhập (User Login).
- Tạo bài viết (Create Blog Post).
- Thêm bình luận (Add Comment).

## 4. Cấu trúc dự án

- Pages: Chứa các trang giao diện Razor Pages.
- Properties: Chứa các cấu hình của dự án.
- wwwroot: Chứa các tài nguyên tĩnh như CSS, JavaScript.
- Program.cs: Cấu hình và khởi chạy ứng dụng.
- LAB_03.csproj: File cấu hình dự án ASP.NET Core.

## 5. Hướng dẫn chạy dự án

1. Tải repository về máy tính.
2. Mở file LAB_03.csproj bằng Visual Studio 2022.
3. Khôi phục các thư viện NuGet nếu cần.
4. Chạy ứng dụng bằng HTTPS.

## 6. Trạng thái dự án

Dự án hiện đang trong quá trình phát triển và hoàn thiện các chức năng của Sprint 1.
